# Запуск на сервере

Нужен постоянно работающий Linux-сервер с Docker и Docker Compose.
Бот использует Telegram polling: домен, HTTPS и открытые входящие порты ему не нужны.
Бесплатные веб-сервисы, которые засыпают без входящих запросов, для этой версии не подходят.

## Установка

1. Склонировать приватный репозиторий на сервер.
2. Создать `.env` по `.env.example`, заполнить токены и Telegram ID владельца.
   Не загружать `.env` в GitHub, не вставлять токены в команды оболочки.
3. Остановить локальный бот перед включением серверного: одновременно должна работать одна копия.
4. Перенести актуальную SQLite-базу `database/student.db` в `data/student.db` на сервере
   по SSH/SFTP. Копировать после остановки бота. Базу не загружать в GitHub.
   Так сохранятся настройки, отмены, переносы, задания и история уведомлений.
5. Запустить:

```sh
docker compose up -d --build
docker compose logs --tail=100 bot
```

Проверить строку `Bot is polling`, синхронизацию Canvas и команды в Telegram.
`restart: unless-stopped` восстанавливает бот после сбоя или перезапуска сервера.
SQLite и логи сохраняются в `./data`, независимо от пересоздания контейнера.

## Обновление

```sh
git pull --ff-only
docker compose up -d --build
```

Не запускать несколько реплик бота. Перед изменениями сохранять резервную копию
`data/student.db` (после остановки сервиса либо через SQLite Backup API).
При истечении Canvas-токена заменить его в `.env` и пересоздать контейнер.
Бесплатные лимиты и доступность сервера нужно проверять у выбранного провайдера.
